# Metmma Pharmacy website

A responsive, static landing page based on the supplied Figma PDF design. It uses the logo and medicine artwork extracted from the PDF.

## Preview

Open `index.html` in a browser, or serve the project folder locally:

```sh
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.

The contact and newsletter forms provide front-end preview states only. They do not send or store submissions. The phone, email, and opening hours remain placeholders because the design did not include those details.
